# Test fixtures

These files are the importer test resources of Aegis Authenticator
(`app/src/test/resources/com/beemdevelopment/aegis/importers`,
https://github.com/beemdevelopment/Aegis, GPL-3.0-or-later). They are real exports from the
respective apps with invented accounts, and the encrypted ones use the password `test`. They
check this module against files other apps actually wrote. Self-made fixtures (every unusual
case) are built in `FixtureBuilders.kt`.
